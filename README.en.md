## Purpose

GitHub automatically applies the templates in this repository to every project that does not define its own files with the same names. Maintaining them here gives all projects under this account a consistent contribution workflow and reporting channel.

| File | Purpose |
| :--- | :--- |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Contribution workflow, development environment, and commit message guidelines |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Code of conduct for contributors |
| [`SECURITY.md`](SECURITY.md) | Security vulnerability reporting channel and response commitment |
| [`PULL_REQUEST_TEMPLATE.md`](PULL_REQUEST_TEMPLATE.md) | Pull request template |
| [`ISSUE_TEMPLATE/`](ISSUE_TEMPLATE) | Issue form templates (bug reports, feature requests) |

---

## Overriding

If an individual project needs its own guidelines, simply place a file with the same name in the project root — GitHub will prefer the project's own version.
