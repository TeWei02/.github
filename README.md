## 用途

GitHub 會自動將這個倉庫裡的範本套用到**未自行定義同名檔案**的所有專案。因此在此處維護一份，即可讓全帳號的專案都具備一致的貢獻流程與回報管道。

| 檔案 | 用途 |
| :--- | :--- |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | 貢獻流程、開發環境與提交訊息規範 |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | 貢獻者行為準則 |
| [`SECURITY.md`](SECURITY.md) | 安全性弱點回報管道與回應承諾 |
| [`PULL_REQUEST_TEMPLATE.md`](PULL_REQUEST_TEMPLATE.md) | Pull request 範本 |
| [`ISSUE_TEMPLATE/`](ISSUE_TEMPLATE) | Issue 表單範本（錯誤回報、功能建議） |

---

## 覆寫方式

個別專案若需要自己的規範，只要在該專案根目錄放入同名檔案即可，GitHub 會優先採用專案自身的版本。
