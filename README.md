# .github

這個倉庫存放 [@TeWei02](https://github.com/TeWei02) 帳號下所有專案共用的社群健康檔案。

GitHub 會自動將這裡的範本套用到未自行定義同名檔案的專案：

| 檔案 | 用途 |
| --- | --- |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | 貢獻流程與提交規範 |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | 貢獻者行為準則 |
| [`SECURITY.md`](SECURITY.md) | 安全性弱點回報管道 |
| [`PULL_REQUEST_TEMPLATE.md`](PULL_REQUEST_TEMPLATE.md) | Pull request 範本 |
| [`ISSUE_TEMPLATE/`](ISSUE_TEMPLATE) | Issue 表單範本 |

個人檔案與研究介紹請見 [個人網站](https://tewei02.github.io/)。
